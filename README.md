# Homebrew Tap

Custom Homebrew formulas by [@swiftlysingh](https://github.com/swiftlysingh).

## Installation

```bash
brew tap swiftlysingh/tap
```

## Available Formulas

| Formula | Description |
|---------|-------------|
| [octl](https://github.com/swiftlysingh/octl) | CLI tool for Microsoft Outlook |

## Usage

```bash
# Install octl
brew install swiftlysingh/tap/octl

# Or after tapping
brew install octl
```
